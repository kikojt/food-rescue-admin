# Food Rescue Admin

A web administration platform for managing food rescue partners and daily surplus food offers. This project was developed as part of a university assignment, inspired by applications such as Too Good To Go.

## Features

### Administrator
- Administrator account creation
- Secure authentication
- Password management
- Dashboard
- Partner management
  - Create new partners
  - View partner details
  - Edit partner information
  - Activate/Deactivate partner accounts

### Partners
- Secure login
- Daily offers management
  - Create offers
  - View offer details
  - Edit offers
  - Delete offers
- Logout

## Technologies

- PHP
- MySQL
- PDO
- Bootstrap
- HTML5
- CSS3
- JavaScript

## Security

- Password hashing using `password_hash()`
- Authentication and session management
- Route protection for authenticated users
- Input validation
- Prepared Statements (PDO) to prevent SQL Injection

## Database

The application uses a MySQL database to manage:

- Administrator
- Partners
- Daily Offers
